# Glossary

Terms you will meet in CritiCall instructions, job postings and these notes.

| Term | Meaning |
|---|---|
| **911 call taker** | The person who answers emergency calls and gathers information. In some centers this is a separate role from the dispatcher. |
| **APCO** | Association of Public-Safety Communications Officials, an industry association for public-safety communications. |
| **CAD** | Computer-aided dispatch. The software dispatchers use to log calls and track units. You do not need to know it for CritiCall. |
| **Call summarization** | A CritiCall module where you listen to a call and capture or select the key facts. The publisher calls it Oral Comprehension. |
| **Chunking** | Grouping digits or letters into small blocks (555, 0143) so they are easier to hold in memory and check. |
| **Conditional offer** | A job offer that depends on passing later steps, such as a background check or medical exam. |
| **CritiCall Classic** | The original set of separate CritiCall skills tests. |
| **CritiCall3D** | The newer version with three parts: Operational, Situational and Behavioral. |
| **Cross Referencing** | A CritiCall module where you find information in lists in response to written or spoken requests. |
| **Decision rules** | The four rules in the candidate preparation guide for choosing Police, Fire, EMS or Utility. |
| **Dispatcher** | The person who sends and coordinates responding units, often by radio. |
| **E911** | Enhanced 911, where the caller's number and location can appear automatically. Also part of some CritiCall test names. |
| **Eligibility list** | A ranked list of candidates who passed, used to decide who is invited to the next step. |
| **EMS** | Emergency medical services, such as ambulances and paramedics. |
| **EQ** | Emotional intelligence. The CritiCall3D Situational test includes an EQ component. |
| **Keyboarding** | A CritiCall module where you copy written paragraphs. The score is in words per minute. |
| **Multitasking (MT)** | Doing two tasks at once, such as typing caller details while answering emergency messages. Some test names include MT. |
| **NENA** | National Emergency Number Association, an industry association for 911. |
| **OneTest** | The CritiCall3D Operational test that combines eight classic tests in one. |
| **Position Locating** | A CritiCall module where you find a caller's position on a map from clues. |
| **Practice items** | Unscored items at the start of each section that show you how to respond. |
| **Proctoring** | Supervision of a test. TestGenius offers remote proctoring that records the screen and webcam. |
| **PSAP** | Public safety answering point, the formal name for a center that answers 911 calls. |
| **Telecommunicator** | A general title covering call takers and dispatchers. |
| **TestGenius** | Biddle Consulting Group's testing platform. CritiCall runs on it. |
| **VIN** | Vehicle identification number, a 17-character code that identifies a vehicle. |
| **WPM** | Words per minute, the unit for the keyboarding score. |
| **Work-sample test** | A test that has you do a simplified version of the actual work, rather than answer questions about it. |
