# The CritiCall test explained

CritiCall is a computer-based pre-employment test for 911 and public-safety dispatchers, call takers and telecommunicators. It is made by Biddle Consulting Group and runs on its TestGenius platform. Instead of asking what you know about dispatch, it puts you in a simulated, generic dispatch setting and checks whether you have the underlying skills: typing, listening, remembering, reading maps, making quick decisions and doing several things at once.

## Quick facts

| | |
|---|---|
| Publisher | Biddle Consulting Group, Inc., as part of the TestGenius suite |
| Type of test | A work-sample test that simulates a generic dispatch environment |
| Test library | More than 20 different tests. Each agency picks the ones it wants. |
| Length | Depends on the modules your agency assigns. The publisher's applicant FAQ says one to three hours on average, and its help center recommends setting aside two to three hours to finish in one sitting. |
| Versions | CritiCall Classic, and CritiCall3D, which adds Situational and Behavioral parts to the Operational skills tests |
| Delivery | Online, self-administering and self-scoring. Agencies can let applicants test remotely, and can add remote proctoring. |
| Device | A laptop or desktop computer. The help center says some modules do not work on phones or tablets. |
| Prior experience | None needed. The publisher says applicants need no dispatch experience or training. |
| Pass mark | None published by the publisher. Each agency sets its own standard. |
| Who uses it | More than 1,400 agencies, including more than half of US state police and highway patrol agencies, according to the publisher |

## What the test is really checking

The publisher's applicant FAQ lists the skills you need: multitasking, prioritization, map reading, memory recall, comprehension, probability, data entry and decision-making. Its candidate preparation guide adds a practical point: you also need to be comfortable using a computer, because some decision items appear while you are busy with another task.

That is the job in miniature. A dispatcher listens to a caller, types the details into the right fields, checks a map, decides who to send, and answers the radio, often all within the same minute.

The publisher's test list also includes a Vocalization Summary test, which asks you to pick out spoken information using a job-related decision rule. It draws on the same listening skills as call summarization.

## How the test is built

A few things from the publisher's candidate preparation guide shape how you should prepare:

- **Practice items come first.** Each section starts with practice items that do not count. You can skip them, but most people should not.
- **You will wear a headset.** Many items are spoken. You can usually adjust the volume.
- **Upper case only, in places.** Many fields accept only capital letters, like real dispatch software.
- **Skipping is penalized** unless the instructions for a section say otherwise.
- **One left click** is all you should use to choose an answer.
- **Decision rules matter.** For the emergency-message items you must use the four decision rules in the guide, not your own knowledge.

## CritiCall Classic and CritiCall3D

The classic version is the set of separate skills tests above. CritiCall3D is the newer version. The publisher describes it in three parts:

- **Operational:** the hard skills. Its OneTest combines eight classic tests into a single test that asks you to make decisions while doing other tasks in a simulated call environment.
- **Situational:** a situational judgment test for emergency dispatch, with an emotional intelligence component.
- **Behavioral:** a personality test that measures overall personality plus Dependability, Confident/Assertive, Resilience/Composure and Management/Prioritization.

The publisher says CritiCall3D tests three times as many job performance areas in the same time as the classic version. Your invitation or the agency's job posting may tell you which version you will take. If it does not, prepare for the skills tests first, since every version includes them.

## Practice the real format

There is no official practice version of CritiCall. The publisher says the software is only available to agencies. It does offer free sample tests for keyboarding, proofreading and spelling, mainly so you can check your device, plus the free candidate preparation guide. Both are linked from the [CritiCall applicant page](https://criticall911.com/dispatcher-testing/applicants).

For a timed run across the modules, try the [free CritiCall practice test on PrepClubs](https://prepclubs.com/free-practice-tests/criticall?utm_source=github&utm_medium=referral&utm_campaign=zse9qc&utm_content=criticall), then take the [diagnostic](diagnostic.md) to see which guide to open first.
